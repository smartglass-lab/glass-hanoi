# グラスハノイ — Glass Hanoi

Meta Ray-Ban Display 用の**ハノイの塔パズル**。3本の柱と3〜7枚の円盤。D-pad の←→で柱をえらび、タップで一番上の円盤を持ち上げて、別の柱でタップして置く。**大きい円盤は小さい円盤の上に置けない**（置こうとすると円盤がやさしく揺れて知らせる）。手数・最短手数（2ⁿ−1）・経過時間がいつも見えていて、こまったら**ヒントで次の最短手を光らせる**こともできる。暗い面に彩度の高いグラデーションの円盤が浮かぶ、加算式ディスプレイ向けの配色。依存ライブラリなし・オフライン動作。

- **ライブURL**: https://glass-hanoi.vercel.app
- **画面**: 600×600 / 加算式ディスプレイ対応（背景 #000000 = 透明）
- **依存ライブラリなし**（Vanilla JS / Canvas / 静的サイト）

## 特徴

- **タップ＋←→だけで遊べる** — 柱をえらぶ→タップで持ち上げ→柱を移ってタップで置く。持ち上げた円盤はカーソルについて柱の上を移動する
- **置けない手はやさしく揺れる** — 大きい円盤を小さい円盤の上に置こうとすると、円盤が揺れて相手の円盤が赤く光る（手数にはカウントしない）
- **手数・最短手数・時間** — 上部に「手数 / 最短 2ⁿ−1 ・ 経過時間」を常時表示。最短手数でクリアすると「PERFECT!」
- **ヒント** — いまの配置から最短でゴールへ向かう次の1手を、金色の矢印と柱の光で示す（途中で遠回りしていても、そこからの最短手を計算）
- **1手もどす／やりなおす** — メニューからいつでも
- **3〜7枚** — 3枚（7手）から7枚（127手）まで。枚数ごとのベスト手数・ベストタイムとクリア回数を保存
- **クリア演出** — ゴールの柱の円盤が順に光り、円盤の色の紙ふぶきが舞う

## 操作方法

| 画面 | 操作 |
|------|------|
| タイトル | ↑↓でえらんでタップ。「円盤」の行は←→（またはタップ）で3〜7枚を切り替え |
| ゲーム | ←→で柱（と左はしの ≡）を移動、タップで持ち上げる／置く／もとの柱にもどす。≡ でタップするとメニュー |
| メニュー | ↑↓でえらんでタップ（「← もどる」「やりなおす」「1手もどす」「ヒント」「つかいかた」「タイトルへ」） |
| クリア | ↑↓でえらんでタップ（「▶ もう一度」「＋1枚でちょうせん」「タイトルへ」） |
| つかいかた | タップで「← もどる」 |
| PC確認用 | Escape でひとつ前の画面へ、柱をクリックで持ち上げる／置く（グラスの戻るジェスチャーは使用不可のため補助のみ） |

`?auto=1` を付けると最短手順の自動再生（デモ録画用。タイトルでタップすると 4 枚で自動再生が始まり、途中で1回だけ「置けない手」の揺れも見せる。記録は保存しない）。`?n=3`〜`?n=7` で枚数を指定できます。

## グラスへの登録

`qr-publish.png` の QR コードをスマホでスキャンすると Meta AI アプリが開き、自動で Web アプリとして登録されます。

ディープリンク:
```
fb-viewapp://web_app_deep_link?appName=%E3%82%B0%E3%83%A9%E3%82%B9%E3%83%8F%E3%83%8E%E3%82%A4&appUrl=https%3A%2F%2Fglass-hanoi.vercel.app
```

手動登録の場合: Meta AI アプリ → デバイス → ディスプレイグラス設定 → アプリ接続 → Web アプリ → 「Web アプリを追加」で名前 `グラスハノイ`、URL `https://glass-hanoi.vercel.app` を入力。
